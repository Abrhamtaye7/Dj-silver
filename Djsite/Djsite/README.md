# DJ Silver Web System

This repository is scaffolded for a MERN stack project (React frontend, Node/Express backend, MongoDB).

## Status
- Project structure initialized
- Frontend scaffolded with Vite + React
- Backend scaffolded with Express
- Tailwind CSS configured
- No feature implementation yet

## Requirements
- Node.js 20+
- npm

## Development
### Frontend
1. cd frontend
2. npm run dev

### Backend
1. cd backend
2. cp .env.example .env
3. npm run dev
